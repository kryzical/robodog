# Scripts Documentation

This directory contains Python scripts for controlling the puppy robot.

## walking.py
Implementation of basic walking gaits for the puppy robot. This script publishes joint positions to make the robot walk.

## stand_up.py
Script to make the puppy robot stand up from a sitting or lying position by calculating appropriate leg angles.

## dummy.py
Updated script that uses puppy_msgs to control the robot's movement with different gait configurations.

## jordan_move.py
Custom movement script with specific motion patterns.

## position_stabilizer.py
Stabilization script that helps maintain the robot's balance by adjusting joint positions.

## adapted_testing.py
Testing script for experimental features and movements.

## __init__.py
Python package initialization file.
