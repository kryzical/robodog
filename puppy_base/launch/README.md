# Launch Files Documentation

This directory contains launch files for the puppy_base package.

## test_walk.launch
Launches the Gazebo simulation with the puppy robot and starts the walking script. 
This is a simple launch file for testing basic walking functionality.

## base.launch
Main launch file for the robot base functionality without simulation.

## simulation_control.launch
Launches the simulation control components for the puppy robot.

## state_estimation.launch
Launches the state estimation nodes for the puppy robot.

## unified_control.launch
Combines multiple control components into a single unified control system.
