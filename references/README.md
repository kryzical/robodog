# References Directory

This directory contains reference materials, templates, and examples that may be useful for the RoboDog project.

## Contents

- `test/`: Contains ROS 2 Humble Docker templates from https://github.com/sskorol/ros2-humble-docker-dev-template

## Purpose

This directory serves as an archive for code, configurations, and templates that might be useful as references but are not directly part of the project codebase. It's intended to store examples, configurations, and other resources that could be helpful for future development without cluttering the main project structure.

## Usage

Browse these directories for examples and reference materials when implementing similar functionality in the main project. You can copy and adapt code from here, but avoid directly importing these files into the project as they are meant to be references only.
