PUPPY_NAVIGATION PACKAGE
======================

Navigation and autonomous movement package for the puppy robot:

Key Components:
- Move_base integration
- Path planning
- Obstacle avoidance
- Localization (AMCL)
- SLAM capabilities

Directories:
/launch - Navigation launch files
/maps - Saved environment maps
/param - Navigation parameters
/rviz - Navigation visualization configs

Features:
- Autonomous navigation
- Map creation and management
- Path planning and execution
- Real-time obstacle avoidance
- Position estimation

Dependencies:
- ROS Navigation Stack
- AMCL for localization
- Map Server
- Move Base
- TF2 for transformations
