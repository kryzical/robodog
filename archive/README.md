# Archive Directory

This directory is used to store historical or deprecated files from the RoboDog project that we may want to reference later but are no longer part of the active codebase.

## Purpose

The archive serves several purposes:
1. Preserves historical code/configurations for reference
2. Removes deprecated files from the active codebase to prevent confusion
3. Maintains a record of past approaches/solutions for future consideration

## Organization

Files in this directory are generally organized by their purpose or the component they were associated with. Each major component or subsystem may have its own subdirectory.

## Usage

This directory is intended for reference only. Files here should not be directly imported or used in the active codebase. If you need to reuse code from the archive, copy the relevant portions to the appropriate location in the main project structure.
