# Documentation

This directory contains documentation for the Puppy Robot project.

## Files

- `Docker_Optimization_Guide.md`: Guide for optimizing Docker builds for the Puppy robot
- `ROS1_to_ROS2_Migration.md`: Documentation on migrating from ROS 1 to ROS 2
- `ros2_conversion_plan.md`: Plan for converting packages to ROS 2

These documents provide guidance on various aspects of the project development and maintenance.
